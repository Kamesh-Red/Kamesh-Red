An end-to-end data analytics project analyzing **3,900+ customer transactions** to identify customer behavior, revenue trends, subscription patterns, shipping preferences, and customer segments.

**What I worked on:**

* Cleaned and transformed data using **Python & Pandas**
* Handled missing values and performed feature engineering
* Used **SQL/PostgreSQL** for business analysis
* Analyzed revenue, subscriptions, customer segments, and shipping trends
* Built an interactive **Power BI dashboard**
* Created KPIs and visual insights for decision-making

**Tech Stack:**

`Python` `Pandas` `SQL` `PostgreSQL` `Power BI` `Excel`
